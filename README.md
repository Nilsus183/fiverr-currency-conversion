# Fiverr Währungsumrechner

Ein kleines React/Vite-Projekt zum schnellen Umrechnen von Fiverr-Preisen zwischen USD und EUR.

Die Website zeigt zusätzlich eine einfache Übersicht, was Verkäufer nach der Fiverr-Gebühr ungefähr erhalten und was Käufer inklusive Fiverr-Gebühr ungefähr zahlen.

## Website

https://fiverr-currency-conversion.pages.dev/

## Funktionen

- Umrechnung von USD zu EUR
- Umrechnung von EUR zu USD
- Anzeige des Verkäuferbetrags nach Fiverr-Gebühr
- Anzeige des ungefähren Käuferpreises inklusive Fiverr-Gebühr
- Hell- und Dunkelmodus
- Sprachumschaltung
- Einfache, responsive Oberfläche

## Hinweis

Die Berechnung basiert auf einem fest hinterlegten Umrechnungskurs und dient nur zur Orientierung.
